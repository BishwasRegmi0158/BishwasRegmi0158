## 🚀 Featured Projects

### 🔹 [BookMyServe](https://github.com/BishwasRegmi0158) — Freelance/Gig Marketplace Backend
Spring Boot backend for a multi-role service marketplace (Client / Provider / Admin).
- JWT-based auth with **access + refresh token rotation**, multi-session login support
- Role-based access control across three user types
- PostgreSQL (Neon) with clean layered architecture: DTOs, mappers, service layer
- Centralized exception handling via `@RestControllerAdvice` with a consistent API response shape
- **Stack:** Java · Spring Boot · Spring Security · PostgreSQL · JWT

### 🔹 [journalApp](https://github.com/BishwasRegmi0158/journalApp) — Journal Backend with Caching & Automation
Spring Boot journal API with production-style features beyond basic CRUD.
- Redis caching layer for performance
- Scheduled sentiment-analysis email job (weekly cron)
- OpenWeatherMap API integration
- Spring Security 6 (`SecurityFilterChain`), BCrypt password hashing
- **Stack:** Java · Spring Boot · MongoDB Atlas · Redis · Spring Security

### 🔹 [ServiceHub](https://servicehub-bishwash-b18b1.web.app) — AI-Powered Service Booking App
Full-stack app connecting users with local service providers via an AI chat assistant (Gemini API).
- FastAPI backend feeds live provider data into Gemini for grounded, non-generic recommendations
- Flutter (Material 3) frontend, deployed on Firebase Hosting + Render
- **Stack:** Flutter · FastAPI · Google Gemini API
